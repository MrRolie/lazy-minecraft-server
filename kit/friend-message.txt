2. Install the modpack
I'm sending you a file with this message: {pack_file}. Import it into a launcher. Either of these works:
- Prism Launcher (https://prismlauncher.org): Add Instance > Import > pick the file > OK.
- Modrinth App (https://modrinth.com/app): Create new instance > Upload a modpack > pick the file. It may warn that the pack isn't hosted on Modrinth ("unknown modpack"): that's expected, so go ahead.

Give it 4-6 GB of memory:

- Modrinth App: open the instance's settings and find Custom memory allocation (recent versions have it under Sync overrides) > 4096-6144 MB.

When a new chapter comes out, I'll send you a new pack file. Import it the same way and play on the new instance. Your builds and items live on the server, so nothing is lost. You may have to redo your keybinds and video settings.
